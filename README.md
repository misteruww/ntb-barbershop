# NTB — Neyro The Barber

Página de NTB Barbershop, Carolina, Puerto Rico, publicada desde la raíz de `main` con GitHub Pages.

Incluye el perfil, las dos fotos suministradas del local y de Neyro, la entrada con el logo, servicios y acceso a reservas. La agenda utiliza un servidor independiente; este repositorio solo contiene los archivos públicos de la página.

La agenda permanece cerrada hasta configurar el horario del barbero. No procesa pagos ni envía mensajes automáticos.
